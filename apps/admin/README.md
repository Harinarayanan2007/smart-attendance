# Smart Attendance Admin

This app provides the foundation for the admin panel for the Smart Attendance Management System.

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm preview`
- `pnpm lint`
- `pnpm format`
- `pnpm typecheck`

## Stack

- React 19
- Vite
- TypeScript
- React Router
- Tailwind CSS
- TanStack Query
- Zustand
- Axios
